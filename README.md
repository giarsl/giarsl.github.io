# GIAR — bản đầy đủ ngày 02/11/2026

Website tĩnh dùng GitHub Pages, không cần cài đặt hoặc build.

## Đăng lên GitHub
1. Mở repository giarsl/giarsl.github.io, nhánh main.
2. Upload toàn bộ nội dung trong thư mục này vào thư mục gốc repository.
3. Giữ nguyên cấu trúc assets/; index.html nằm ở gốc, không nằm trong thư mục bao ngoài.
4. Commit changes. Trong Settings > Pages, dùng Deploy from a branch: main / (root).
5. Chờ GitHub Pages triển khai xong, mở https://giarsl.github.io/.

Không cần xoá repository hoặc thay đổi cấu hình Pages. Có thể ghi đè file trùng tên.
File .nojekyll là file ẩn; website này không phụ thuộc vào nó để hoạt động.

## Tiến độ có trong gói
- Home với câu “Một cá nhân khám phá và thể hiện góc nhìn cá nhân qua kiến trúc, hình ảnh và ngôn ngữ thị giác.”
- Work, Experiments, About và Contact; menu Contact dẫn đến cột liên hệ trong About.
- Chuyển ngôn ngữ EN/VI và hiệu ứng hiện có.
- Instagram @_giarsl ở Home và phần liên hệ.
- Favicon mark.svg; đường dẫn CSS/JS có mã phiên bản để tránh cache cũ.
- Ảnh chân dung còn là khung tạm; Email và TikTok chưa có thông tin.

Kiểm tra: cú pháp JavaScript, liên kết/tài nguyên nội bộ, anchor, mã phiên bản và tính toàn vẹn ZIP.
Chưa xác nhận thao tác menu/ngôn ngữ trên bản gói mới bằng trình duyệt; chưa tự đăng lên GitHub.
